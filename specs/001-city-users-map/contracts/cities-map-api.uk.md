# API-контракт: ендпоінти мапи міст та учасників міста

Це наявні backend-ендпоінти, які споживає ця функція (не створюються цією функцією). Задокументовано тут як клієнтський контракт, якому мають відповідати Flutter DTO (`CityMapPointDto`, `CityMemberDto`); точні назви полів/форму пагінації слід підтвердити за живим бекендом під час реалізації та оновити цей файл відповідно до реальності.

## `GET api/cities/map`

Повертає кожне місто, в якому є хоча б один учасник, для рендерингу міток на мапі.

**Запит**: параметри запиту не очікуються (повний список); стандартний заголовок автентифікації (`HEADERS(token)` за конвенцією проєкту).

**Відповідь** (200): JSON-масив точок мапи міст.

```json
[
  {
    "id": 12,
    "name": "Kyiv",
    "latitude": 50.4501,
    "longitude": 30.5234,
    "users_count": 3,
    "avatar": "https://.../avatar.jpg"
  }
]
```

**Відображення на клієнті** → `CityMapPointDto` (див. `data-model.md`): `avatar` → `avatarUrl` (nullable), `users_count` → `usersCount`.

**Обробка помилок**: будь-яка відповідь не 200 або мережева помилка → екран показує ненав'язливий SnackBar з повтором (FR-016); мапа лишається інтерактивною.

## `GET api/cities/{id}/users`

Повертає пагінований список учасників, розташованих у вказаному місті, для шторки.

**Запит**: параметр шляху `id` (id міста, `int`), параметр(и) запиту для пагінації — конвенція номера сторінки TBD за живим бекендом (наявний патерн `SearchUser.dart` використовує query-параметр `page` та визначає `hasMore` з `results.length >= pageSize`; застосувати той самий підхід тут, якщо бекенд не повертає явне поле `has_more`/`next_page`).

**Відповідь** (200): JSON-масив (або пагінована обгортка) учасників міста.

```json
[
  {
    "id": 42,
    "name": "Oleh Ivanenko",
    "profile_image": "https://.../profile.jpg",
    "roles": ["driver"],
    "telegram_nickname": "oleh_tt",
    "instagram_nickname": null,
    "updated_at": "2026-06-01T10:00:00Z"
  }
]
```

**Відображення на клієнті** → `CityMemberDto` (див. `data-model.md`).

**Обробка помилок**: будь-яка відповідь не 200 або мережева помилка під час завантаження сторінки → ненав'язливий SnackBar з повтором, обмежений цією сторінкою (FR-017); не закриває шторку і не відкидає вже завантажені рядки.
